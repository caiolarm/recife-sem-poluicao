PROTÓTIPO ACADÊMICO

Ajude a registrar pontos de poluição

Esse projeto foi criado para testar uma forma simples de registrar poluição em rios, canais e áreas da orla do Recife.

Como usar

1. Escolha o tipo de poluição.
2. Informe o local.
3. Escreva uma descrição.
4. Se quiser coloque uma foto.
5. Clique para enviar.

Esse projeto é somente um protótipo acadêmico e não envia a denúncia para nenhum órgão público.

Sobre

Objetivo

O objetivo é testar uma ideia de aplicativo que ajude pessoas a registrar locais com poluição e organizar essas informações.

Como foi feito

O protótipo foi feito usando HTML, CSS e JavaScript. Os registros ficam salvos no navegador usando localStorage.

Importante

Esse sistema é só um projeto acadêmico e não substitui canais oficiais de denúncia.
